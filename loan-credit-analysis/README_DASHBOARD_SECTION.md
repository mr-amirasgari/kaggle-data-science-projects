### Interactive Dashboard

This project includes a responsive React dashboard built with TypeScript, Vite, Tailwind CSS, shadcn-style UI patterns, Recharts, and Vitest.

The dashboard presents:
- project overview and reported metrics
- model comparison
- SMOTE / class-imbalance workflow
- an interactive **Credit Risk Scenario Analyzer**
- project and deployment information

> **Note:** The interactive scenario analyzer is a transparent browser-side educational scoring tool. It is intentionally not presented as the fitted notebook model because the trained model artifacts/coefficients are not bundled into the frontend.
